Semantic vector search over pages previously stored with `web_index`; no network fetch. Use to pull passages back out of already-indexed pages: query in plain language, get top chunks with similarity scores (highest first, ~1 = near-exact). Scope to the `namespace` used at index time (default `web`). Empty result → index the page first with `web_index`; weak scores → rephrase or search the live web with `web_search`.
