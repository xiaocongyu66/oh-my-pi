Fetch a URL and store it in the persistent RAG store as embedded chunks for later semantic recall. Use to build a recallable corpus: index pages worth remembering, then search them with `web_recall` instead of re-fetching. Re-indexing a URL replaces its stored chunks. Default namespace `web`; pass `namespace` to keep corpora separate. `max_chunks` caps stored chunks when a page is huge or only the opening matters.
